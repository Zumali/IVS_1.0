# Incentive Validation System - Version 1.0 - Landing page

A responsive landing page built with semantic HTML5 and custom CSS3 features.

## 🚀 Features
- Fully responsive layout for mobile, tablet, and desktop
- Clean, semantic HTML structure
- Custom CSS styling and layout transitions

## 🛠️ Tech Stack
- **HTML5:** Page structure and content
- **CSS3:** Styling, grid layouts, and positioning

## ⚙️ How to Run Locally
1. Clone this repository or download the ZIP file.
2. Open the `index.html` file directly in any web browser.
