# Incentive Validation System - Version 1.0 - Landing page

A responsive landing page built with semantic HTML5 and custom CSS3 features.

## Problem
Readers who preorder a book need a simple way to submit proof
of purchase and provide the information required to receive
their preorder incentives.

## Users
- Readers submitting preorder claims
- Publishing team reviewing and fulfilling claims

## MVP Goal
Create a mobile-friendly workflow that allows readers to
submit their information and receipt with clear validation
and confirmation.

## Product Process
Requirements → Backlog → Prioritization → Development →
Stakeholder Validation → Iteration

## Features
- Fully responsive layout for mobile, tablet, and desktop
- Clean, semantic HTML structure
- Custom CSS styling and layout transitions

## Tech Stack
- **HTML5:** Page structure and content
- **CSS3:** Styling, grid layouts, and positioning

## How to Run Locally
1. Clone this repository or download the ZIP file.
2. Open the `index.html` file directly in any web browser.
